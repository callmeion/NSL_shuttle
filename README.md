# Dashboard รถเสริมรับส่งพนักงาน

หน้าเว็บไฟล์เดียว (`index.html`) อ่านข้อมูลจาก **`data.xlsx`** ทุกครั้งที่เปิดหน้า — ไม่มีข้อมูลฝังในโค้ด

## รูปแบบไฟล์ (ตาม `template_bus_data.xlsx`)
แถว 1 = ชื่อตาราง, แถว 2 = หัวคอลัมน์, ข้อมูลเริ่มแถว 3 (1 แถว = 1 วัน) — ใช้ได้ทั้งชีตเดียวยาวทั้งปี หรือแยกชีตตามรอบบิล (อ่านทุกชีต)

| คอลัมน์ | ความหมาย |
|---|---|
| A | วันที่ |
| B | จำนวนรถเสริมตามบิล/วัน (= ยอด manual) |
| C | ค่าใช้จ่ายต่อวัน (ว่าง/สูตร = B × 320) |
| D | หมายเหตุ |
| E, F | ผู้โดยสาร รับ / ส่ง (คน) |
| G | รถบริษัท |
| H | รถเสริมในระบบ (= ยอดในระบบ) |
| I | ค่าใช้จ่ายในระบบ (ว่าง = H × 320) |
| J, K | ส่วนต่างเที่ยว/บาท (สูตรในไฟล์ — Dashboard คำนวณเอง) |

แถวที่ A ไม่ใช่วันที่ (เช่น รวม/เฉลี่ย) หรือ B ว่าง จะถูกข้าม

## อัปเดตข้อมูล
เพิ่มแถวใน `data.xlsx` แล้ว commit + push → หน้าเว็บอัปเดตเอง

## Deploy (GitHub Pages)
Settings → Pages → Source: **GitHub Actions** แล้ว push เข้า `main` (`.github/workflows/pages.yml`)
ทดสอบในเครื่อง: `python3 -m http.server` แล้วเปิด http://localhost:8000 (ดับเบิลคลิกเปิดไฟล์ตรงๆ จะอ่าน data.xlsx ไม่ได้)
